# Self-host vLLM with a public HTTPS endpoint

Example Nethera app for the [vllm recipe](https://nethera.io/docs/recipes/vllm).

## Notes

This example expects a GPU-enabled machine and may need a model-specific image/config update before use.

## Deploy

From this directory:

```bash
neth init
neth deploy
```

Open the endpoint printed by `neth deploy`.
